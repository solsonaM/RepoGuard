RepoGuard

Audit a GitHub repository before you install it.

What RepoGuard checks

Secrets, malware-like static patterns, auto-run hooks, dependency advisories, archives, binaries, AI-skill prompt injection, and repository reputation signals.

Security model

The target repository is treated as hostile data. RepoGuard never installs, imports, builds, or executes target files during hosted scanning.

No scanner can guarantee the absence of all threats.
